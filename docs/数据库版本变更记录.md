# 数据库版本变更记录

变更编号：DB-001。确认日期：2026 年 11 月 16 日。确认人：组长 MFJ-123，承担 A 部分。组长已确认调整数据库版本并要求同步仓库说明。

| 项目 | 原约定 | 新约定 |
| --- | --- | --- |
| 数据库服务 | MySQL 8.4 | MySQL Server 8.0.46 社区版 |
| 业务表引擎 | InnoDB | InnoDB |
| 管理工具 | 未单独指定 | 可使用 MySQL Workbench 8.0 CE |

本次调整适配组长电脑上已安装的 MySQL Server 程序版本。实际连接的数据库版本仍须执行 `SELECT VERSION();` 核对；Workbench 的版本不能作为服务端版本证明。全组的开发、迁移、测试与部署按 8.0.46 对齐。

现有设计采用的事务、行锁、外键、生成列、唯一索引和 CHECK 约束继续保留。各模块仍须在目标版本完成实际建表及业务验证，不能将文档兼容性核对视为测试已经通过。

受影响范围为 A 的工程配置和驱动选型、D 的迁移登记、全组数据库开发与部署，以及 SAR-SYS-0040、TC-13 和相关并发、事务、备份恢复验证。功能、接口字段、权限及质量门槛沿用原约定；目前仓库尚无应用源码或数据库迁移，因此本次没有数据迁移或程序配置变更。

README、后端说明、迁移说明、部署说明、测试说明和分工方案已同步。`docs/baseline/` 下两份 Word 原文及其哈希保留为历史基线；其中关于数据库版本的约定由本记录替代。后续修订 Word 或 PPT 时同步该选型。

实施验收：A 核对连接版本及驱动；D 验证空库建表、后续升级和唯一约束；各负责人验证事务与并发；A/C 完成数据库及附件同批次备份恢复。所有业务验收状态仍以实测证据登记。

兼容性依据：[MySQL Workbench 与 MySQL Server](https://dev.mysql.com/doc/workbench/en/)、[MySQL 8.0 生成列索引](https://dev.mysql.com/doc/refman/8.0/en/create-table-secondary-indexes.html)、[MySQL 8.0 CHECK 约束](https://dev.mysql.com/doc/refman/8.0/en/create-table-check-constraints.html)。
